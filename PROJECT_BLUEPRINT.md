## 🧱 2. Complete Website Architecture & Features

### 🌌 1. Hero Section
* Cinematic dark background with subtle gold party aura.
* Bold brand title: **BEYOND HOURS**
* Core tagline display.
* Quick action CTAs: *"Explore Next Party"* & *"Book / Inquire"*.

### 📊 2. Live Instagram Stats Bar
* **Auto-update / Live sync** for:
  * Total Posts Count
  * Followers Count
  * Following Count
* Sleek count-up animation when scrolling.
* Direct *"Follow on Instagram"* badge.

### 🌟 3. Hero / Featured Frames
* Top curated marquee moments & flagship party visual showcases.

### ⚡ 4. Latest Drops (2 Dedicated Content Slots)
* **Slot 1: Latest Reel** — Vertical (9:16) interactive frame for the newest party reel/video.
* **Slot 2: Latest Post** — Square/portrait photo frame with caption preview and IG direct link.
* Easy to update whenever fresh content drops on IG.

### 📅 5. Upcoming Events & Dynamic Gallery
* **Events Section:** Cards for upcoming parties, dates, venues, pass booking/RSVP status.
* **Gallery Grid:** High-energy photo collage from past parties.
* Modular design so adding new events/photos is simple.

### 📝 6. VIP / Party Inquiry Form
* Client booking / event organizer form:
  * Full Name
  * WhatsApp / Phone Number / IG Handle
  * Event Type (Private Party, Club Night, Birthday, After-Hours Gathering, Custom Event)
  * Expected Date & Approximate Guest Count
  * Custom notes / requests
* **Instant Action:** Direct WhatsApp auto-message generation for instant response and booking.

### ⭐ 7. Party-Goer Feedback & Vibe Rating
* **Interactive Star / Vibe Rating:** (1 to 5 Stars / 🔥 Vibe meter)
* **Attendee Review Form:**
  * Name / IG Handle
  * Event Attended (e.g. "Last Saturday Night", "Neon Afterhours")
  * Rating & Vibe feedback ("Music", "Crowd", "Ambience", "Overall Vibe")
  * Short review / memory quote
* **Live Testimonial / Social Proof Cards:**
  * Wall of love showing top reviews & quotes from party attendees to build hype and credibility for upcoming events.
